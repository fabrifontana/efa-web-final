# EFA Diseño Web - Final

Este es mi proyecto final. El formulario en React pide datos personales, de contacto y de estudio. Node.js los recibe y los muestra en la consola.

## Para ejecutarlo

```bash
npm install
npm run dev
```

Después, abrimos una pestaña en: http://localhost:3000.

Al enviar el formulario, los datos aparecen en la consola del servidor. No se guardan, pero dan un feedback al usuario igualmente.
